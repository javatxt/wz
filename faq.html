进服全流程指引 · 从下载到登录一步不落

一 · 进服须知

服务器地址：nyj.cc.cd

支持版本：1.12 - 26.2，强烈推荐使用 26.2 版本

  • 电脑：PCL2 启动器
  • 手机安卓：FCL（Fold Craft Launcher，运行 Java 版）
⚠️ 手机不是网易 / 基岩版。FCL 运行的是 Java 版 MC，和电脑是同一个客户端协议。

二 · 电脑端进服教程（PCL2）

  1. 下载 PCL2（可在首页下载文件下载），解压到非中文路径，运行 Plain Craft Launcher 2.exe
  2. 顶部点【下载】→【原版游戏】正式版，找到 26.2（Paper26.2），点击开始下载，等待资源全部补全下载完成
    如果你要玩旧版本，可下载 1.12 - 26.2 之间任意版本，但必须和服务器版本匹配，优先 26.2。
  3. 账号设置：
    正版：填入微软账号登录
    离线：切换离线模式，填写你的游戏 ID（名字不能中文特殊符号）
  4. 版本选择选好刚刚下载的 26.2，点击【启动】进入游戏
  5. 主界面点【多人游戏】→【添加服务器】
    服务器名称：闲云阁（随便填）
    服务器地址：nyj.cc.cd
    端口保持默认，不需要填端口号
  6. 点完成，双击服务器进入。如果服内提示注册，按聊天框提示执行 /register 密码 确认密码 注册账号，后续登录用 /login 密码

三 · 电脑常见报错

  • 连接超时：检查网络、关闭防火墙，确认版本是 26.2
  • 版本不匹配：客户端版本必须落在 1.12 - 26.2 区间，优先 26.2
  • 无法验证：离线账号名字不要带中文、emoji

四 · 手机安卓教程（FCL）

  1. 获取 FCL 启动器安装包，安装后打开，允许存储权限
  2. 左侧菜单点【下载】，找到版本 26.2，下载原版 / Paper 客户端，等待全部资源下载完毕
    手机性能差可以选低版本，但必须在 1.12 - 26.2 范围内，推荐 26.2。
  3. 账号管理：新建离线账号，填写英文 / 数字游戏 ID（和电脑一样最好，不要中文）
  4. 在版本列表选中 26.2，点击【启动游戏】
  5. 进入 MC 主界面，点【多人游戏】→【添加服务器】
    💡 FCL 虚拟键盘小技巧：点击输入框，点界面上方 [input] 调出手机输入法，不然无法输入文字。
    • 服务器名称：闲云阁
    • 服务器地址：nyj.cc.cd
    • 端口：不需要填写（默认不动）
  6. 点击完成，选中服务器加入。进服提示注册执行 /register 密码 确认密码，登录用 /login 密码

五 · FCL 手机常见问题

  1. 点输入框打不出字：务必点 [input] 按钮唤起输入法，不要直接点击屏幕输入框
  2. 游戏闪退：分配内存调低至 2 - 3G；渲染器切换 Zink / VirGL；关闭光影；不要开太多后台软件
  3. 连接失败：确认下载的是 Java 版 26.2，不是基岩版；网络切换流量 / Wi-Fi 重试
  4. 资源包弹窗：如果弹出服务器资源包询问，选「否」——部分手机开启会直接卡死闪退

六 · 通用注意事项

  1. 版本规则：客户端版本必须在 1.12 - 26.2，最优 26.2，版本不对直接连不上
  2. 账号名规则：离线账号名字禁止中文、特殊符号、emoji，否则服务器拒绝登录
  3. 注册须知：第一次进服要注册账号，记住你的密码，丢密码需要找服主重置
  4. 反作弊：不要使用作弊客户端，服务器有反作弊检测会直接封禁
  5. 进不去排查顺序：网络 → 版本 → 账号名字 → 防火墙 → 是否开启代理 / VPN
